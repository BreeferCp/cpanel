## Installing

On a fresh, dedicated Ubuntu 24.04 server:

```bash
V=0.5.0; A=amd64   # or arm64 (built, not tested)
curl -fLO https://github.com/BreeferCp/cpanel/releases/download/v$V/breefercp-$V-linux-$A.tar.gz
curl -fLO https://github.com/BreeferCp/cpanel/releases/download/v$V/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
tar xzf breefercp-$V-linux-$A.tar.gz && cd breefercp-$V-linux-$A
sudo ./deploy/install.sh --email you@example.com --hostname panel.example.com
```

Then set the server IP and nameservers in WHM.

## If you run an earlier build from source

**Earlier builds have critical security flaws. Upgrade now with the installer**, not with `breeferd update` or the Updates page, which cannot apply these fixes:

1. Back up `/var/lib/breefercp` and `/etc/breefercp`. The installer rewrites `breefercp.conf`.
2. Run the installation steps above with your existing email and hostname.
3. Assume the server may have been tampered with. Check root's SSH keys, `/etc/cron.d`, sudoers and system users, look for hosted domains that their account does not own, and change database passwords.

### What was wrong

- Customers could gain root through SSH keys, document roots, web server logs and app names.
- Customers could read and change other customers' databases, and read their website files through symlinks.
- Customers could claim domains they did not own and receive their mail.
- Password-protected folders could be bypassed, and dotfiles downloaded.
- Signed-in mail senders could be forged, and catch-all addresses captured mailbox mail.
- The installer, the systemd unit, HTTPS vhosts, mail delivery and the self-updater did not work on a real server.

## New

- Backup download and restore of files and databases
- User Manager, Address Importer and Email Disk Usage
- Leech Protection, wildcard redirects and proof of domain ownership
- Monthly bandwidth accounting and archived logs
- Key and CSR generator, AutoSSL exclusions and scheduled issuance
- Database check and repair, cron email and more email notices
- A friendlier UI, especially on phones

## Testing

Tested end to end on Ubuntu 24.04 amd64 (under WSL 2). Not tested on a real host: Debian, other Ubuntu versions, arm64, real Let's Encrypt issuance, OpenLiteSpeed, Docker apps, the WordPress toolkit, FTP transfers, webmail sign-in, the firewall and PostgreSQL. See the [README](https://github.com/BreeferCp/cpanel/blob/v0.5.0/README.md#project-status).

Customers now have to prove control of a domain before adding it. Accounts created by administrators, resellers and billing systems skip that check.
